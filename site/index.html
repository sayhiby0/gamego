  1. 开通普通模型 API。使用阿里云账号按控制台提示完成服务开通、实名等要求。购买的是普通模型 API 调用能力，不是聊天会员；Coding Plan 编程订阅及其专用 Key 不能用于本网站。
  2. 先查价格与额度。阅读官方模型计费说明：输入与输出 Token 分别计费，价格随模型、地域而异。按实际需要充值或购买适用额度，不保证免费或固定单次费用；平台支持时设置余额／用量提醒。网站不代充值、不补贴，也不另设助手月度金额上限。多个 Key 不代表独立余额或配额。
  3. 创建专用普通 Key。参照官方获取指南，在API Key 控制台切换正确地域，选择所属账号／业务空间及模型权限。建议专用 Key 和最小所需权限，不建议全部权限。复制普通 API Key，勿发送到聊天、邮件、截图或公开仓库。
  4. 回到配置面板。选择 Key 对应地域和站主已验收模型，粘贴到遮蔽输入框，自主选择是否记住，再保存。Key 是凭据，模型是请求选择，不是上传 AI 助手。接口地址由本站维护，不能自填。保存与恢复都不调用模型。
  5. 主动测试，再开始研究。点击“测试连接”并确认费用。成功仅代表当时可调用所选模型；选 game-daily 提问“整理近期游戏发行动态”，或选 game-monitor 填写一至两款游戏，再点击“开始分析”，逐条查看来源。测试、提问、追问和重试都可能收费，停止只尽力取消，已受理调用仍可能计费。
  6. 按原因排错。错 Key／已撤销：核对普通 Key；余额／额度不足：查百炼账户；无权限／地域不匹配：核对业务空间、地域、模型权限；限流：稍后手动重试；网络／中转失败：检查网络与服务状态，不关闭浏览器安全设置。错误原因未知时本站不会猜测或显示原始调试详情。
  7. 清除与撤销不同。清聊天保留配置；清除 API 会停止本页任务并清除本页 Key、对话及本地保存项。泄露时到百炼控制台删除旧 Key，立即失效且不可恢复；必要时先创建替代 Key 再撤销旧 Key。只清本机不等于撤销平台凭据。
  8. 了解数据边界。Key 经过本站轻量后端与百炼，仅用于本次模型鉴权，不交给公开取证来源，不落本站后端持久存储。模型与搜索服务会接收所需内容，其保留政策独立于本站。记住不是保险箱，同一 GitHub Pages 域名下其他路径项目同源可读，前缀不能隔离；共享设备不建议保存。刷新、关闭和离开页面清空对话，无跨设备历史。仅支持站主验收列表；当前中国手游稳定榜单、完整近期评论及部分搜索来源仍有缺口，没有来源就如实披露，不把模型知识当最新舆情。
